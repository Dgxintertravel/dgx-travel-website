## Entrega e preparação

- Enviar JPG de boa qualidade ou WebP, preferencialmente em sRGB, sem texto sobreposto ou marca d'água.
- Não ampliar uma foto pequena artificialmente para atingir as medidas. Se o original for maior, enviar o original.
- Os recortes variam entre desktop e celular; deixar margem em torno do assunto e informar o ponto de interesse quando necessário.
- Para publicação, preparar versões otimizadas em WebP/JPG; meta de 150–400 KB para fotos editoriais e até cerca de 700 KB para imagens amplas, conforme a qualidade visual permitir. Estes são objetivos de otimização, não limites para o arquivo original enviado.
